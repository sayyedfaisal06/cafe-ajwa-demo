# Cafe Ajwa — Client

Customer-facing website for Cafe Ajwa, built with Vite, React, TypeScript and Tailwind CSS v4.

Project docs live in [`docs/`](docs/):
- [current-website.md](docs/current-website.md): audit of the existing site
- [redesign-plan.md](docs/redesign-plan.md): redesign plan
- [gaps-and-bugs.md](docs/gaps-and-bugs.md): missing features and bugs

## Scripts

| Command | What it does |
|---|---|
| `npm run dev` | Start the dev server |
| `npm run build` | Type-check and build for production into `dist/` |
| `npm run preview` | Serve the production build locally |
| `npm run lint` | Lint with oxlint |
